اپ «مشاور — گزارش ماهیانه» (کاملاً آفلاین)

روش ۱ (ساده): فایل index.html را روی گوشی در Chrome باز کنید.
روش ۲ (پیشنهادی، نصب مثل اپ): پوشه را یک‌بار روی هر هاستینگ ساده (مثلاً GitHub Pages یا هاست شخصی با HTTPS) آپلود کنید،
در Chrome گوشی باز کنید و «Add to Home screen / نصب برنامه» را بزنید. از آن پس بدون اینترنت کار می‌کند.

* اطلاعات روی حافظهٔ همان دستگاه ذخیره می‌شود؛ از صفحهٔ اصلی «دریافت پشتیبان» بگیرید.
* خروجی PDF: در پنجرهٔ چاپ «ذخیره به‌صورت PDF» را بزنید (A4 افقی خودکار).
